# What a setting changes in the Items screens

Status: Measured / Seen come from the connectivity map; "To confirm" means I still have to check the ERP.

| Screen element | Controlled by | Status |
|---|---|---|
| Quantity decimals everywhere | Items settings > Preferences > decimal places | Measured |
| Dimensions and weight unit labels (forms) | Items settings > Preferences | Measured |
| Default valuation method (new item) | Items settings > Preferences | Measured |
| Stock panel, Adjust Stock, Reorder Point | Items settings > Enable Inventory Tracking | Measured |
| Serial / Batch choice on the form, Batches tab | Items settings > Advanced Inventory Tracking | Measured |
| Locations tab and stock locations table | Organization > Locations (and the item must hold stock) | To confirm |
| Associated Price Lists | Items settings > Price Lists (price lists on/off) | To confirm |
| Reporting Tags section | Customization > Reporting Tags | To confirm |
| Retail Preference section | Module Settings > Retail | To confirm |
| Share Hosted Payment Page (services) | Online Payments settings | To confirm |
| Required marker, hidden or inactive fields | Items settings > Fields | Measured |
| Locked tag, Lock / Unlock, refused edit | Items settings > Record Locking | Measured |
| Extra buttons in the item header | Items settings > Buttons | Measured |
| Extra tab with a table | Items settings > Related Lists | Measured |
| Save refused with a custom message | Items settings > Validation Rules | Measured |
| Replenishment filters in the list | Items settings > Replenishments | Seen |
